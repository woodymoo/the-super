Use the workflow tool to run a parallel, read-only pre-release audit of this
repository. Launch the following 4 subtasks in parallel:

1. architecture
   Check module boundaries, dependency direction, circular dependencies, and
   unreasonable coupling.
2. correctness
   Check error handling, null handling, concurrency issues, boundary conditions,
   and resource leaks.
3. tests
   Check coverage gaps, brittle tests, and missing exception-path tests.
4. security
   Check input validation, command execution, path traversal, sensitive data,
   and permission issues.

Requirements:
- The workflow tool must be used
- All subagents are read-only; modifying files is forbidden
- Each subagent returns a structured result
- On subagent failure, keep null; do not retry indefinitely
- Deduplicate the findings at the end and sort by severity
- Every finding must include severity, file, evidence, and recommendation
- Return at most the 15 most important findings
- Use phase and log markers for the execution stages
- Return a JSON-serializable result
